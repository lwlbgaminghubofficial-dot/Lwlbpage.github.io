# 🎨 Portfolio الشخصي | Personal Portfolio

موقع portfolio احترافي وعصري مع تصميم حديث وميزات متقدمة.

## 🌟 المميزات الرئيسية

✨ **التصميم:**
- تصميم عصري واحترافي
- واجهة مستخدم جميلة وسهلة الاستخدام
- Animations و Transitions سلسة
- تأثيرات بصرية مذهلة

🌙 **Dark Mode / Light Mode:**
- تبديل سهل بين الوضع الليلي والنهاري
- حفظ التفضيلات في localStorage

📱 **Responsive Design:**
- يعمل بشكل مثالي على جميع الأجهزة
- Desktop, Tablet, Mobile متوافق تماماً
- أداء عالي وتحميل سريع

🎯 **الأقسام:**
- **Hero Section** - صفحة ترحيبية جذابة
- **About** - معلومات عني والمهارات
- **Projects** - عرض المشاريع بتصميم احترافي
- **Contact** - نموذج تواصل متقدم
- **Footer** - تذييل بسيط واحترافي

⚡ **الميزات التفاعلية:**
- Navigation smooth
- Form validation
- Social links
- Parallax effects
- Scroll animations
- Mobile menu

## 💡 نصائح التخصيص

### 1. تغيير الألوان
عدّل متغيرات CSS في `style.css`:
```css
:root {
    --primary-color: #YOUR_COLOR;
    --secondary-color: #YOUR_COLOR;
    --accent-color: #YOUR_COLOR;
}
```

### 2. إضافة مشاريع جديدة
انسخ عنصر `project-card` وعدّل البيانات:
```html
<div class="project-card">
    <div class="project-image">
        <i class="fas fa-icon"></i>
    </div>
    <h3>عنوان المشروع</h3>
    <p>وصف المشروع</p>
    <!-- ... -->
</div>
```

### 3. تعديل معلومات التواصل
حدّث البيانات في قسم Contact:
```html
<p>your.email@example.com</p>
<p>+966 xx xxx xxxx</p>
```

### 4. إضافة روابط وسائل التواصل
عدّل الروابط الاجتماعية:
```html
<a href="https://github.com/username" class="social-link">
    <i class="fab fa-github"></i>
</a>
```

## 🌐 نشر الموقع

### استخدام GitHub Pages (الطريقة الأفضل)

2. اذهب إلى Settings > Pages
3. اختر Branch و Deploy
4. الموقع سيكون متاحاً على: `https://lwlbgaminghubofficial-dot.github.io/`
